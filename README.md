# Nathália Luiza da Fontoura — Portfólio

Portfólio pessoal desenvolvido para apresentar minha formação, experiências, cursos, habilidades e conhecimentos na área de tecnologia.

## 👩‍💻 Sobre o projeto

Este projeto consiste em um site de portfólio pessoal desenvolvido com HTML, CSS e JavaScript.

O objetivo é apresentar de forma organizada informações acadêmicas e profissionais, além de conhecimentos em informática, programação, UI/UX e ferramentas digitais.

## 🎯 Objetivos

- Apresentar minha formação acadêmica.
- Mostrar experiências profissionais e participações em projetos.
- Apresentar cursos e conhecimentos adquiridos.
- Destacar minhas principais habilidades e competências.
- Disponibilizar informações de contato profissional.
- Praticar desenvolvimento web e organização de projetos com Git e GitHub.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
